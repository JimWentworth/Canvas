About the Faculty AI Content Tool

The Faculty AI Content Tool is designed to help educators quickly create comprehensive course content for Canvas LMS using AI-powered content generation.

Features

  • AI-Powered Content Generation: Uses Claude AI to generate high-quality educational content tailored to your course specifications
  • Structured Course Design: Creates a complete course structure with weekly modules and organized content
  • Introduction Pages: Each week includes an engaging introduction with clearly stated learning objectives
  • Comprehensive Lectures: Detailed lecture content that covers topics thoroughly and pedagogically
  • Canvas Integration: Exports as Common Cartridge 1.1 format for seamless import into Canvas LMS

How It Works

  1. Input Course Details: Provide basic information about your course including name, subject, duration, and target audience
  2. AI Generation: Claude AI analyzes your requirements and generates a complete course structure with weekly topics and learning objectives
  3. Content Creation: For each week, the tool generates:
    • An introduction page with context and learning objectives
    • A comprehensive lecture page with detailed content
  4. Package Export: All content is packaged into a Common Cartridge file that can be imported into Canvas

Requirements

  • An Anthropic API key (set in the .env file)
  • Canvas LMS access with permission to import content
  • A modern web browser

Setup Instructions

  1. Copy .env.example to .env
  2. Add your Anthropic API key to the .env file:
    ANTHROPIC_API_KEY=your_api_key_here
  3. Install dependencies: pip install -r requirements.txt
  4. Run migrations: python manage.py migrate
  5. Start the server: python manage.py runserver
  6. Access the tool at http://localhost:8000

Common Cartridge Format

The tool generates Common Cartridge 1.1 packages, which is an IMS Global Learning Consortium standard supported by Canvas and many other Learning Management Systems. This ensures compatibility and ease of import.

Tips for Best Results

  • Be specific in the subject area field (e.g., "Cognitive Psychology" rather than just "Psychology")
  • Use the additional context field to specify particular topics, themes, or approaches you want included
  • Choose the appropriate target audience to ensure content difficulty matches your students
  • Review and customize the generated content in Canvas after import to add your personal touch

Technology Stack

  • Backend: Python with Django framework
  • AI Engine: Claude API by Anthropic
  • Export Format: IMS Common Cartridge 1.1
