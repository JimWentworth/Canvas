📥 How to Import to Canvas

  1. Download the generated .imscc file
  2. In Canvas, go to your course → Settings
  3. Click Import Course Content
  4. Select Common Cartridge 1.x Package
  5. Upload the .imscc file and click Import
  6. Review and publish the imported content
